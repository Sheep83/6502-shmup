# Reports

Historical engine qualification reports remain in `../6502-engine/reports` —
the aperture forensics, the sprite-band A/B, the architecture reviews and the
four implementation slices. That repository is the archaeology and stays
authoritative for it.

This directory is for **6502-shmup** development reports from this point onward.

Per `AGENTS.md`: a substantial investigation goes here as a markdown file *and*
is printed normally in the reply. Transient captures and logs do not — they go
to `/tmp` and are cleaned up.
